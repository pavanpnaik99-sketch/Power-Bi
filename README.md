# 📊 Power BI Assignment – End-to-End Analytics Workbook

This repository contains a single Power BI workbook (`.pbix`) that covers multiple real-world Power BI scenarios including DAX, data modeling, visualizations, bookmarks, drill-through, and dashboard creation.

All assignment questions are solved in **one consolidated Power BI file**, as required.

---

## 🛠 Tools & Technologies
- Power BI Desktop  
- DAX (Data Analysis Expressions)  
- Power Query (ETL)  
- Data Modeling  
- Interactive Visualizations  

---

## 📁 Datasets Used
- Superstore Dataset  
- Finance Dataset  
- Worldwide Box Office Dataset (Box Office Mojo – past 3 years)
